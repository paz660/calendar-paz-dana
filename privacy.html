Privacy Policy

Calendar Paz&Dana is a private Android TV screensaver used by a single household. Last updated: November 2026.

What data the app accesses

With the explicit consent of each account owner, the app reads calendar events (title, time, location, description, calendar name and colour) through the Google Calendar API, using the read-only scope https://www.googleapis.com/auth/calendar.readonly. It does not request any other Google data.

How the data is used

The data is used only to display upcoming events on the household's TV screen. The app never creates, modifies or deletes events, and never responds to invitations.

Where the data is stored

Events and the OAuth refresh token are stored only on the TV device. The token is encrypted with a key held in the Android Keystore. There is no server: the device talks directly to Google. No data is sold, shared, transferred to third parties, used for advertising, or used to train AI models.

Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Each account owner can disconnect at any time from the app's settings on the TV, which revokes access and deletes that account's data from the device, or at myaccount.google.com/permissions. Uninstalling the app deletes all stored data.

Contact

Questions: use the support email shown on the Google sign-in consent screen for this app.
